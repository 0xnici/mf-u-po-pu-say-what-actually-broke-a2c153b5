A single-line error message for the exact moment a save fails because the disk is full. The copy names the real failure ("Disk full"), tells the user the one action that fixes it (free space), and the joke is the explanation itself — we can't write more because there's no room, which is *why* the save failed. No padding, every clause does double duty.

Built for [make.fun](https://make.fun/?ref=1n20pv53).
